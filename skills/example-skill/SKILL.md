# example-skill

## このスキルがやること

3. 最後に〜を確認する

## 使い方のメモ
- frontmatter の `name` がスラッシュコマンド名になります（`/example-skill`）。
- `description` は自動選択の判断材料。具体的な使用条件を書くほど精度が上がります。
- 補助ファイル（スクリプトやテンプレート）はこのディレクトリ内に置いて相対参照できます。
